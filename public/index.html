Sheet 01

Personal · Full-stack · Markets

A portfolio terminal I built for my own accounts

Problem

Broker apps show my positions but not the analysis I want. Paid terminals cost far more than a student can spend.

What I built

Aurora is a private portfolio terminal for my Vanguard and Robinhood accounts, plus bank and card spending. It installs on my iPhone as a web app, signs me in with Face ID and sends push alerts. Beyond holdings, it has news, markets and spending screens, and a page for every ticker with candlestick charts and fundamentals. An AI assistant answers questions about the screen I'm on and writes a morning brief and a weekly review. Before any of that text is shown, a number guard checks every figure in it against the source data.

It runs on Cloudflare Workers with a D1 (SQLite) database, a five-minute scheduler and plain JavaScript, with no framework. Holdings come in read-only through Plaid. Prices, filings and macro data come from Finnhub, Tiingo, Alpha Vantage, FMP, FRED and the SEC, and a call budget keeps each source inside its free limit. Private data is encrypted at rest, and nothing in the app can move money. An optional helper on my laptop runs a local model for background reading and makes nightly encrypted backups. I built it with Claude Code; the repository is named Finance Watch.

Result

In daily use on my phone, with 123 automated tests. I also ran a security review of my own app, fixed each finding in its own commit with a test that failed before the fix, and added automated checks that run before every commit.

Sheet 02

GE Vernova · Shop-floor connectivity · Embedded Linux

CNC data off the dot-matrix printer

Problem

A Daewoo Mynx 500 machining center with a Fanuc 21-M controller could only send its output over a serial line to a dot-matrix printer. Those printers are old and increasingly expensive to keep running, and they leave the data on paper only.

What I built

A Raspberry Pi running Linux captures the controller's serial output (RS-232, 7E2, through a TRENDnet TU-S9 USB-serial adapter) and puts it on the network. A Python print helper on the shop-floor Windows PC, packaged as an .exe with PyInstaller, sends it to a networked Brother HL-L2405W laser printer over Wi-Fi.

Around it, a scheduled Robocopy job with filtering and logging files CNC output on a network share. I also changed the plant's legacy VB6 DNC software so G-code files open in an editor (portable Notepad++) instead of printing, behind a config flag.

Result

The dot-matrix printers are retired. One problem is still open: making the print helper survive Windows updates without a weekly reinstall.

Read as finance

A build-versus-buy call: a cheap gateway instead of replacing a machine that still cuts metal well.

GE Vernova · Metrology · Numerical methods

Correcting CMM probe offsets

Problem

A coordinate measuring machine records each touch as a point and a surface direction: XYZ plus the IJK normal. If the probe's offsets are slightly wrong, every measurement inherits the error.

What I did

Working with the plant's metrology lead, I estimated offset corrections from XYZIJK data with a least-squares fit. Then I checked the results against what beam theory predicts for the probe.

Result

A validated method: the fitted corrections agreed with the beam-theory prediction, an independent physical model.

Read as finance

Least squares is the method behind linear regression; here the fit had to agree with an independent physical model before anyone trusted it.

Sheet 04

GE Vernova · Program management · IT security

MFA device rollout

Problem

More than 200 people at the plant needed multi-factor authentication devices. There weren't enough units, eligibility wasn't clear, and many people work on the shop floor across different shifts.

What I did

I ran the rollout over several months. I sourced extra units from other GE teams and wrote a Python scraper that pulled employee data from an internal system to work out who was eligible. An Excel register matched every serial number to its recipient. I held office hours, and I tracked down shop-floor workers on every shift for one-on-one setup walkthroughs.

Result

More than 200 devices issued and set up, each one traceable to a person.
